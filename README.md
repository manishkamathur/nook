# Nook extension

Source for the Nook Chrome extension. The website lives on the `main` branch.

- `nook/` is the extension. Load it unpacked from `chrome://extensions`, or zip its contents for the Chrome Web Store.
- `preview/` runs the extension's pages in a normal browser with sample data: `node preview/serve.mjs`, then open http://localhost:5178/preview/nook.html
